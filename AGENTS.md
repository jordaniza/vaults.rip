# Repository guidance

- Design files and rules live in `design/`; follow `design/DESIGN_SPEC.md`.
- Canonical website copy lives in `content/index.md`.
- Start with `llms.txt` for the machine-readable website map.
- `main.js` renders the Markdown content into `index.html`; do not duplicate substantive copy in the HTML.
- Treat `content/index.md` as canonical and check `README.md` for copy drift whenever content changes and during periodic repository maintenance.
