# vaults.rip

vaults.rip is a technical knowledge base of documented DeFi vault and market failure cases.

## How to use this site

Treat this file as a directory, not as the research corpus.

1. Identify the protocol, component or failure mode relevant to the vault, market or task being reviewed.
2. Scan the case directory below and open only the cases that may be relevant.
3. Use the linked `/content/cases/<protocol>/<number>.md` documents as the primary machine-readable sources.
4. Read a case's Summary first to establish relevance, then inspect its remaining sections for context, evidence, examples and ways to address the condition.
5. Do not assume that a case applies solely because its protocol or component matches. Compare the case's specific conditions with the system being reviewed.

## Page hierarchy

- [`/llms.txt`](https://www.vaults.rip/llms.txt) is this routing document and the generated case directory.
- [`/content/index.md`](https://www.vaults.rip/content/index.md) contains the website overview and a generated directory of all cases. It is useful for broad orientation but is not required for most case-specific work.
- `/content/cases/<protocol>/<number>.md` is the canonical machine-readable version of an individual case. Direct links are listed below.
- `/cases/<protocol>/<number>/` is the human-readable rendering of a case. Use it when the rendered diagrams or visual presentation are useful.
- [`/`](https://www.vaults.rip/) is the human-readable homepage and case index.
- [`/skills.md`](https://www.vaults.rip/skills.md) is work-in-progress guidance intended to become a broader review procedure.
